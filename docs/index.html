Real-Time Chat API (1.1.0)

Download OpenAPI specification:

License: MIT

Real-time messaging platform with voice/video calling. Built with Go, GORM, PostgreSQL, Redis, and WebSockets.

Reliability features:

  • Keyset (cursor) pagination on messages
  • Idempotent message send via client_message_id
  • Transactional outbox + Redis pub/sub for cross-instance fan-out
  • WebSocket auth on upgrade via ?token= (Clerk JWT)

Real-time

WebSocket endpoint for real-time events

Upgrade to WebSocket for real-time messaging. Connect as wss://host/ws?token=<clerk_jwt> (production uses /chat-ws?token=...).

Client → Server events:

  • register-user — { userId }
  • register-peer — { userId, peerId }
  • get-peer-id — { targetUserId }
  • join-room — { chatId }
  • leave-room — { chatId }
  • typing — { chatId, userId, username }
  • stop-typing — { chatId, userId }
  • send-message — { chatId, content, clientMessageId?, fileUrl?, fileName?, fileType?, fileSize? }
  • resync — { chatId, afterSeq } (replay messages after a seq on reconnect)
  • call-user — { targetUserId, callerId, callerUsername, callerAvatar, isVideo }
  • call-answered — { targetUserId }
  • call-rejected — { targetUserId }
  • end-call — { targetUserId }

Server → Client events:

  • receive-message — full Message object (sent to the whole room; the sender gets their own message back via its subscription)
  • resync-messages — { chatId, messages }
  • user-typing / user-stop-typing
  • join-room-error / send-message-error — { error, ... }
  • incoming-call — { callerId, callerUsername, callerAvatar, isVideo }
  • user-busy — { targetUserId }
  • call-answered / call-rejected / call-ended
  • error

Server sends ping frames and expects pong back (60s idle timeout).

Authorizations:
None
query Parameters
token
required
string

Clerk session JWT. Auth happens on upgrade (browsers cannot set WS headers).
